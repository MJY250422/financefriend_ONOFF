## 📝 Render 배포 상세 가이드

### 1. Render 가입

1. **https://render.com 접속**
2. **Sign Up with GitHub** 클릭
3. GitHub 계정으로 로그인

---

### 2. Web Service 생성

1. **Dashboard → New +** 클릭
2. **Web Service** 선택
3. **Connect Repository**
   - `MJY250422/financefriend_ONOFF` 선택
   - 또는 저장소 URL 입력

4. **기본 설정**
   ```
   Name: financefriend-backend
   Region: Singapore (가장 가까운 서버)
   Branch: feature/connect_streamlit_fastapi
   Root Directory: system_design
   Runtime: Python 3
   ```

5. **Build & Start Commands**
   ```
   Build Command: pip install -r requirements.txt
   Start Command: python main.py
   ```

6. **Instance Type**
   ```
   Free (무료 플랜)
   - 512MB RAM
   - 0.1 CPU
   - 자동 슬립 (15분 미사용 시)
   ```

---

### 3. 환경 변수 설정 ⭐ 중요!

**Environment Variables** 섹션에서 추가:

```env
DATABASE_URL
postgresql://postgres:[PASSWORD]@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres

API_HOST
0.0.0.0

API_PORT
8000

API_RELOAD
False

ALLOWED_ORIGINS
*

LOG_LEVEL
INFO
```

**주의:**
- `DATABASE_URL`에는 실제 Supabase 연결 문자열 입력
- 비밀번호 포함!

---

### 4. 배포 시작

1. **Create Web Service** 클릭
2. 자동으로 배포 시작
3. 로그 확인하며 대기 (약 3-5분)

**성공 메시지:**
```
==> Your service is live 🎉
https://financefriend-backend.onrender.com
```

---

### 5. 배포 확인

**브라우저에서 접속:**
```
https://financefriend-backend.onrender.com/health
https://financefriend-backend.onrender.com/docs
```

**응답 확인:**
```json
{
  "status": "healthy",
  "message": "All systems operational",
  "version": "1.0.0"
}
```

---

### 6. 팀원들 설정

**팀원들에게 공유할 정보:**

```
백엔드 API URL: https://financefriend-backend.onrender.com
API 문서: https://financefriend-backend.onrender.com/docs
```

**팀원들이 할 일:**

1. **프로젝트 클론 (아직 안 했다면)**
   ```bash
   git clone https://github.com/MJY250422/financefriend_ONOFF.git
   cd financefriend_ONOFF
   git checkout feature/connect_streamlit_fastapi
   ```

2. **프론트엔드 설정**
   
   `streamlit/api_client.py` 수정:
   ```python
   # 기존
   BASE_URL = "http://localhost:8000"
   
   # 변경
   BASE_URL = "https://financefriend-backend.onrender.com"
   ```

3. **프론트엔드 실행**
   ```bash
   cd streamlit
   conda activate financial_friend_minzero
   streamlit run app.py
   ```

## ⚠️ Render 무료 플랜 주의사항

### 자동 슬립 (Auto-Sleep)
- 15분 동안 요청이 없으면 서버가 슬립 상태로 전환
- 다음 요청 시 자동으로 깨어남 (약 30초 소요)

**해결책:**
1. 처음 접속 시 30초 정도 기다리기
2. 또는 유료 플랜 사용 ($7/월)

### 빌드 시간
- 매번 배포 시 3-5분 소요
- Git push 후 자동 재배포
