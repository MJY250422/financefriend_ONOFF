## 1. 프로젝트 소개

### 🎯 프로젝트 개요
- **이름**: FinanceFriend
- **목적**: AI 기반 금융 뉴스 추천 및 챗봇 서비스
- **기술 스택**:
  - **백엔드**: FastAPI + SQLAlchemy
  - **프론트엔드**: Streamlit
  - **데이터베이스**: Supabase PostgreSQL (클라우드)
  - **AI**: OpenAI API

### 📁 프로젝트 구조
```
financefriend_ONOFF/
├── system_design/              # 백엔드 (FastAPI)
│   ├── main.py                # FastAPI 메인 애플리케이션
│   ├── database.py            # DB 연결 설정
│   ├── routers/               # API 엔드포인트들
│   ├── schemas.py             # Pydantic 모델
│   ├── db_schema_design.py    # DB 테이블 정의
│   ├── .env                   # 환경 변수 (생성 필요!)
│   └── venv311/               # Python 가상환경
│
├── streamlit/                 # 프론트엔드 (Streamlit)
│   ├── app.py                 # 메인 앱
│   ├── api_client.py          # 백엔드 API 클라이언트
│   └── .streamlit/secrets.toml # OpenAI API 키 (생성 필요!)
│
├── START_BACKEND_SERVER.bat   # 백엔드 자동 실행 스크립트
├── START_FRONTEND_APP.bat     # 프론트엔드 자동 실행 스크립트
```

## 4. 환경 설정

### Step 1: 백엔드 가상환경 설정

```bash
# system_design 폴더로 이동
cd system_design

# 가상환경 생성 (Python 3.11 사용)
python -m venv venv311

# 가상환경 활성화 (Windows)
.\venv311\Scripts\activate

# 패키지 설치
pip install -r requirements.txt
```

**설치되는 주요 패키지:**
- fastapi
- uvicorn
- sqlalchemy
- psycopg2-binary (PostgreSQL)
- pydantic
- python-dotenv

---

### Step 2: 환경 변수 설정 (.env 파일)

**⚠️ 중요: `.env` 파일은 Git에 올라가지 않으므로 직접 생성해야 합니다!**

#### 방법 1: 템플릿 복사
```bash
# system_design 폴더에서
cp env_template.txt .env
```

#### 방법 2: 직접 생성
`system_design/.env` 파일을 생성하고 아래 내용을 입력:

```env
# 데이터베이스 설정 (Supabase PostgreSQL)
# 👉 팀장에게 실제 값을 받아서 입력하세요!
DATABASE_URL=postgresql://postgres:[비밀번호]@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres

# API 서버 설정
API_HOST=0.0.0.0
API_PORT=8000
API_RELOAD=True

# CORS 설정 (프론트엔드 접속 허용)
ALLOWED_ORIGINS=http://localhost:8501,http://127.0.0.1:8501

# 로그 설정
LOG_LEVEL=INFO
```

**🔑 DATABASE_URL 받는 방법:**
1. 팀장에게 요청
2. 또는 `CREDENTIALS_SETUP.md` 파일 참조 (팀 내부 문서)

---

### Step 3: 프론트엔드 환경 설정 (Conda 사용)

**Conda 가상환경을 사용하는 경우:**

```bash

cd ..\streamlit
```

## 7. 문제 해결

### ❌ 문제 1: "ModuleNotFoundError"

**증상:**
```
ModuleNotFoundError: No module named 'fastapi'
```

**해결:**
```bash
# 가상환경이 활성화되었는지 확인
# 프롬프트에 (venv311) 표시가 있어야 함

# 패키지 재설치
pip install -r requirements.txt
```

---

### ❌ 문제 2: "CORS 에러"

**증상:**
```
Access to fetch at 'http://localhost:8000/api/v1/users/' 
from origin 'http://localhost:8501' has been blocked by CORS policy
```

**해결:**
`system_design/.env` 파일 확인:
```env
ALLOWED_ORIGINS=http://localhost:8501,http://127.0.0.1:8501
```

서버 재시작.

---

### ❌ 문제 3: "데이터베이스 연결 실패"

**증상:**
```
could not translate host name to address
```

**해결:**
1. `.env` 파일의 `DATABASE_URL` 확인
2. 팀장에게 올바른 연결 문자열 요청
3. Supabase Connection Pooler URL 사용 확인:
   ```
   postgresql://postgres:[PASSWORD]@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres
   ```

---

### ❌ 문제 4: "포트 이미 사용 중"

**증상:**
```
[Errno 10048] error while attempting to bind on address ('0.0.0.0', 8000)
```

**해결:**
```bash
# 포트 8000 사용 중인 프로세스 찾기
netstat -ano | findstr :8000

# 프로세스 종료 (PID 확인 후)
taskkill /PID <PID> /F
```

---

### ❌ 문제 5: "Streamlit 앱이 백엔드에 연결되지 않음"

**체크리스트:**
- [ ] 백엔드 서버가 실행 중인가? (http://localhost:8000/health)
- [ ] `.env`의 `ALLOWED_ORIGINS`에 Streamlit URL이 포함되어 있나?
- [ ] `streamlit/api_client.py`의 `BASE_URL`이 올바른가?
- [ ] 방화벽이 포트를 차단하고 있지 않은가?
