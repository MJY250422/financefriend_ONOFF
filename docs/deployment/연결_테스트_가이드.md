# 프론트엔드-백엔드 연결 테스트 가이드

## 🚀 실행 순서

### 1단계: 백엔드 서버 실행 (필수!)

**터미널 1 (백엔드)**
```powershell
# 방법 1: 배치 파일 실행 (추천)
.\START_BACKEND_SERVER.bat

# 방법 2: 수동 실행
cd system_design
.\venv311\Scripts\activate
python main.py
```

**확인사항:**
- ✅ 서버가 시작되면: `Uvicorn running on http://0.0.0.0:8000`
- ✅ 브라우저에서 확인: http://localhost:8000/health
- ✅ API 문서: http://localhost:8000/docs

---

### 2단계: 프론트엔드 앱 실행

**터미널 2 (프론트엔드)**
```powershell
# 방법 1: 배치 파일 실행 (추천)
.\START_FRONTEND_APP.bat

# 방법 2: 수동 실행
conda activate financial_friend_minzero
cd streamlit
streamlit run app.py
```

**확인사항:**
- ✅ 앱이 시작되면: `You can now view your Streamlit app in your browser`
- ✅ 자동으로 브라우저 열림: http://localhost:8501

---

### 3단계: 연결 테스트

#### ✅ 테스트 1: 백엔드 연결 확인

Streamlit 앱의 **사이드바**에서:
1. 백엔드 URL 확인: `http://localhost:8000`
2. **"🔌 연결 확인"** 버튼 클릭
3. ✅ "✅ 백엔드 연결 성공!" 메시지 확인

#### ✅ 테스트 2: 사용자 생성

Streamlit 앱에서:
1. 사용자 정보 입력 (이메일, 비밀번호 등)
2. "사용자 생성" 버튼 클릭
3. ✅ 성공 메시지 확인

#### ✅ 테스트 3: 뉴스 목록 조회

Streamlit 앱에서:
1. "뉴스 목록 조회" 버튼 클릭
2. ✅ 샘플 뉴스 데이터 표시 확인

#### ✅ 테스트 4: API 직접 호출 (선택)

**PowerShell에서 테스트:**
```powershell
# Health Check
Invoke-WebRequest -Uri http://localhost:8000/health -UseBasicParsing

# 사용자 목록 조회
Invoke-WebRequest -Uri http://localhost:8000/api/v1/users/ -UseBasicParsing

# 뉴스 목록 조회
Invoke-WebRequest -Uri http://localhost:8000/api/v1/news/ -UseBasicParsing
```

## 🔧 문제 해결

### ❌ "백엔드에 연결할 수 없습니다"

**원인:**
- 백엔드 서버가 실행되지 않았음
- 포트 8000이 이미 사용 중

**해결:**
1. 백엔드 터미널 확인: `python main.py`가 실행 중인지
2. 포트 확인: `netstat -ano | findstr :8000`
3. 포트가 사용 중이면: 프로세스 종료 또는 `.env`에서 다른 포트 설정

### ❌ "Streamlit을 찾을 수 없습니다"

**원인:**
- Conda 환경이 활성화되지 않음
- Streamlit이 설치되지 않음

**해결:**
```powershell
conda activate financial_friend_minzero
pip list | findstr streamlit  # 설치 확인
```

### ❌ "CORS 에러"

**원인:**
- 프론트엔드 URL이 백엔드의 `ALLOWED_ORIGINS`에 없음

**해결:**
`system_design/.env` 파일 확인:
```env
ALLOWED_ORIGINS=http://localhost:8501,http://localhost:3000
```
