**작성일**: 2025.11.05  
**목적**: 팀원들이 각자의 장소에서 같은 백엔드 서버와 데이터베이스를 사용하여 협업

---

## 📊 현재 상황

| 구성 요소 | 위치 | 팀원 접근 가능 여부 |
|---------|------|------------------|
| **데이터베이스** | Supabase (클라우드) | ✅ 가능 (이미 설정됨) |
| **백엔드 서버** | 로컬 (localhost:8000) | ❌ 불가능 |
| **프론트엔드** | 각자 로컬 | ⚠️ 각자 실행 필요 |

## 🎯 협업 전략

### 전략 A: 로컬 서버를 외부에 노출 (임시/테스트용)
- **장점**: 빠르게 시작 가능 (5분 소요)
- **단점**: PC를 항상 켜둬야 함, 불안정할 수 있음
- **추천 대상**: 빠른 테스트, 데모, 단기 협업

### 전략 B: 백엔드를 클라우드에 배포 (권장) ⭐
- **장점**: 안정적, 24시간 운영, 프로페셔널
- **단점**: 초기 설정 시간 필요 (30분~1시간)
- **추천 대상**: 장기 프로젝트, 실제 서비스 운영

## 🚀 방법 1: ngrok으로 로컬 서버 노출 (빠른 시작)

### Step 1: ngrok 설치

1. **ngrok 다운로드**
   - https://ngrok.com/download
   - 회원가입 (무료)

2. **설치 및 인증**
   ```bash
   # ngrok 설치 후
   ngrok config add-authtoken YOUR_AUTH_TOKEN
   ```

### Step 2: 백엔드 서버 실행

```bash
# 터미널 1: 백엔드 서버 실행
cd system_design
.\venv311\Scripts\activate
python main.py
```

### Step 3: ngrok으로 외부에 노출

```bash
# 터미널 2: ngrok 실행
ngrok http 8000
```

**화면에 나타나는 정보:**
```
Forwarding   https://abc123.ngrok-free.app -> http://localhost:8000
```

### Step 4: 팀원들에게 URL 공유

**팀원들에게 전달할 정보:**
```
백엔드 API URL: https://abc123.ngrok-free.app
API 문서: https://abc123.ngrok-free.app/docs
Health Check: https://abc123.ngrok-free.app/health
```

### Step 5: 팀원들 - 프론트엔드 설정 변경

팀원들이 `streamlit/api_client.py` 파일 수정:

```python
# 기존
BASE_URL = "http://localhost:8000"

# 변경 (ngrok URL로)
BASE_URL = "https://abc123.ngrok-free.app"
```

### Step 6: 백엔드 CORS 설정 추가

`system_design/.env` 파일에 ngrok URL 추가:

```env
ALLOWED_ORIGINS=http://localhost:8501,http://127.0.0.1:8501,https://abc123.ngrok-free.app
```

서버 재시작!

---

## ⚠️ ngrok 사용 시 주의사항

1. **무료 플랜 제한**
   - 세션 타임아웃: 2시간 (재실행 필요)
   - URL이 매번 바뀜 (유료 플랜에서는 고정 가능)

2. **보안**
   - 누구나 URL을 알면 접속 가능
   - 민감한 데이터 주의

3. **안정성**
   - PC를 계속 켜둬야 함
   - 네트워크가 끊기면 서비스 중단

```bash
cd financefriend_ONOFF
git checkout feature/connect_streamlit_fastapi
```

**2. 프론트엔드 환경 설정**
```bash

pip install -r requirements.txt
```

**3. API URL 변경**

`streamlit/api_client.py` 수정:
```python
# 클라우드 백엔드 URL로 변경

```

**4. 프론트엔드 실행**
```bash
streamlit run app.py
```
